# Security policy

## Supported versions

Security fixes are applied to the current main branch and latest published release.

## Reporting a vulnerability

Please avoid publishing exploitable details in a public issue. Use GitHub's private vulnerability reporting feature when available, or contact the repository owner privately.

Profile bundles are ZIP-based configuration files. The importer constrains paths, entry sizes, and supported fields, but users should still import `.lpm` files only from trusted sources.
